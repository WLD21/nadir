## Corrections and limits

First-pass evidence is retained separately. Fixed logo clipping, mobile inspection/tab overlap, mobile model clipping, compact-phone hero framing and the Dutch three-line headline. Final screenshots supersede those affected early captures.

An intermittent Chrome GLB request event reported ERR_ABORTED in one reduced-motion run and an interaction run, despite every page reaching modelReady=true and painting the complete scene. Three isolated lifecycle checks found one such notification after HTTP 200 and complete delivery of all 4,259,000 bytes, with no duplicate request or JavaScript error; the other two completed normally. This suggests a browser event-reporting anomaly rather than missing content, but that diagnosis is an inference. The ScrollCraft suites were clean. The diagnostic evidence is retained.

Real iPhone/Android hardware, Safari, Low Power Mode and slow mobile GPUs were not tested. Headless mobile viewports are emulation. Google Fonts is external and has sans-serif fallbacks. This static Site does not collect appointments or send email until a real destination is configured. A downloaded brief is not a sent request or confirmed booking.
